# 用户旅程页面取代抖音式单页舞台

状态：已接受（2026-07-22）

TrainPal 作为独立产品，不再沿用“抖音视频页＋右侧分析面板＋固定竖屏手机壳”的整体结构。首版按一个页面一个主要任务拆成首页/导入、分析、方案、首次个性化步骤流、训练中、训练结果和“我的”；首页不模拟信息流，选片后只显示轻量预览并由用户显式开始分析，分析完成后由用户主动进入方案。顶层导航固定为 `首页 / 训练 / 我的`，分析、方案编辑、GYMTI、训练和结果作为沉浸式子流程不显示底部导航；未完成训练通过全局轻量入口恢复。移动端先以单列、至少 44px 触控目标、安全区、底部固定主操作和按需 Bottom Sheet 完成全部任务，桌面端只渐进增加辅助栏或并排预览，不把移动界面装进固定手机模拟器。该选择增加了路由和页面状态恢复要求，但换取更清晰的任务负荷、真实的独立产品心智和可用的移动体验。
