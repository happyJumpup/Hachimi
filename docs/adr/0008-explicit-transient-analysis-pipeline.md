# 动作分析采用显式、临时且可取消的编排管线

> 冲突部分已由 [ADR-0013](0013-local-video-import-and-recoverable-analysis.md) 取代：页面切换、刷新或 SSE 短暂断线不再取消运行；显式编排、测试假实现隔离和临时材料清理继续有效。

首版不使用开放式聊天 Agent、AgentKit、持久任务队列或子 Agent。代码显式并行运行 ASR/训练语音理解与视频视觉定位，再由候选融合 Skill 生成动作候选。分析请求只在内存中存在，用户离开、切换视频或取消后立即失效；本地与提供方临时文件必须在所有终态清除。测试可以注入假适配器，但非测试环境必须拒绝启动假实现。
