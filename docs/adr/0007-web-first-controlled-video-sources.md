# Web-first 使用受控视频源并保留平台适配边界

> 冲突部分已由 [ADR-0013](0013-local-video-import-and-recoverable-analysis.md) 取代：下一轮原型以本地视频导入为主，受控视频源作为兜底；Web-first、禁止任意 URL 和平台适配隔离继续有效。

首个可运行版本采用 Web-first 形态，以团队明确配置的本地或自有视频验证动作分析闭环。浏览器只提交后端发放的 `source_id`，后端不接受任意本地路径、远程 URL 或抖音信息流抓取请求。未来接入抖音端能力时，通过新的来源适配器提供同一受控视频源契约，不改变训练动作、演示片段和方案草稿模型。
