# GYMTI 采用 TrainPal Vue 设计系统

状态：已接受（2026-07-23）

正式 GYMTI 问卷、完善训练档案、结果与风格改选以当前 Vue TrainPal 设计系统为唯一视觉权威，复用手账网格背景、`tp-*` 语义 Token、字体、卡片、胶囊按钮、沉浸式页面、安全区和无障碍规则。问卷原型只提供题目内容、裁去内嵌标题后的 GYMTI 人物插画和经确认可复用的形象素材；其深色遮罩、超大圆角抽屉、独立控件体系、候选轮播、“换一只哈基米”和重复猫头像不进入正式运行时。答题与档案阶段不展示人格插画或小猫，结果只播放推荐猫，改选只播放临时选中猫，低动效模式保持静态。我们放弃原型作为独立视觉模块的完整性，以换取从方案进入问卷、从结果确认七猫、再返回 TrainPal 的连续产品体验。
