# TrainPal 使用温暖训练手账与深色训练舞台

状态：已接受（2026-07-22）

TrainPal 的独立视觉方向是“温暖训练手账 × 小猫教练”。首页、分析结果、方案、个性化和训练结果使用温暖明亮底色、深色正文、大号训练数字和明显留白；只有训练中页面切换为高对比深色舞台，以保证视频、计时和主要控制在健身环境中清晰。小猫教练通过教练卡、贴纸式状态和阶段反馈出现，不复刻抖音右侧悬浮操作栏。全站放弃黑底、电青/珊瑚霓虹、信息流框架和固定 9:16 手机舞台，同时保持运动感而不滑向儿童宠物应用。该方向在规划阶段的轻松感和训练阶段的专注度之间建立明确视觉切换，也为尚未定稿的猫咪资产保留替换空间。
