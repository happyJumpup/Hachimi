# Skill 任务绑定输入版本，并拒绝迟到结果

状态：已接受（2026-07-22）

TrainPal 的每次领域 Skill 任务绑定 `task_id + input_fingerprint + contract_version + skill_version`，相同幂等键的重复提交复用同一次运行或成功结果，避免刷新、网络重试或重复点击再次消耗模型调用。成功结果持久化并保持稳定，只有用户明确重试或重新生成才创建新任务；当输入已经变化、任务已被替换或页面已经接受更新版本时，迟到结果直接丢弃，不能覆盖当前方案。该约束牺牲了后台自动刷新结果的灵活性，换取可解释、可恢复且不会被旧模型响应回写的用户体验。
