# 来源片段默认只作参考，可靠来源节奏才进入执行

状态：已接受（2026-07-22）

所有识别出的训练动作都可以成为候选，来源片段默认只用于观看和找回出处，并在训练页播放一次后暂停；只有明确识别到可靠动作、休息或切换节奏时，系统才附加时间线级节奏块，编译后展开为扁平执行步骤。可靠来源节奏内的重复动作保留为不同执行步骤；没有可靠来源节奏时，标准动作、器械和变式相同的重复演示合并为一个方案动作，只选择证据最完整的连续片段作为训练页参考，其他范围留在只读证据快照中。器械、变式或视频明确参数不同的同名动作保持分开；时间重叠但名称冲突的候选形成一个待确认动作。无法判断来源节奏时按无来源节奏处理，不再让用户判断片段属于教学还是跟练；这一决定取代 ADR-0013 第 7 项及其旧公开片段角色合同，以少量内部节奏判断换取更轻的用户认知和更保守的参数语义。
