# Agent 不长期保存原始媒体和分析材料

> [ADR-0013](0013-local-video-import-and-recoverable-analysis.md) 明确了存储边界：本决策约束服务端与 Agent；用户主动导入的原视频可以保存在当前设备浏览器中，服务端分析副本仍必须在终态清理。

多模态动作分析需要临时处理音频、字幕和关键帧，但长期保存这些内容会扩大隐私、内容授权与存储边界。首版只在当次分析中使用临时材料，持久化用户选中动作的来源引用、时间区间、结构化字段、依据类型和非内容诊断信息；模型评测仅使用团队明确整理和标注的测试素材，以放弃跨请求媒体复用换取清晰的数据边界。
