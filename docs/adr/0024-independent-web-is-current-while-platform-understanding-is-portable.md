# 当前交付为独立 Web，平台内容理解只作为可迁移愿景

状态：已接受（2026-07-22）

TrainPal 当前以独立 Web 和用户本地上传作为真实产品入口，主描述是把用户保存或拥有的健身视频转成可执行训练。“刷到就是练到”保留为品牌价值主张，但比赛演示必须明确选择本地视频，不伪装抖音分享入口、平台合作或已经调用 AI 抖音。理想情况下，TrainPal 的训练编译、个性化调整和动作要点补充能力可以承接抖音 AI 等平台生成的结构化内容理解结果，从而减少重复分析；由于当前接口与技术条件不具备，比赛版继续使用自建内容理解 Provider。该决策让团队可以讲清迁移愿景，同时保持当前交付的真实性。
