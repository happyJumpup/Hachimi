# LLM 只叙述结构化 GYMTI 结果

状态：已接受（2026-07-23）

GYMTI 的正式类型、可选次要倾向、单一教练风格推荐和最多三个关键倾向原因码先由版本化本地合同确定，结果解释 LLM 只把这些结构化事实写成具有变化感的展示文案。原因码只取对最终人格或推荐风格贡献最大的正向已选信号；无信号选项、扣分项和安全硬排除不进入用户叙事。模型不读取逐题题干、完整回答、训练档案、训练历史、身份信息或自由用户画像，也不能重新计分、改变结果或发明推荐依据；原因码由本地规则派生并随评分合同版本化，生成文案不成为稳定个性信息。模型超时、失败或输出无效时，结果页立即改用版本化本地模板，正式结果生效和教练风格确认均不受阻。每份结果只生成一次叙事并保存来源、版本和时间；再次进入直接复用，模板降级也不在模型恢复后自动改写。我们保留问卷过程的变化感，同时让已经交付的测评事实、叙事、隐私边界和推荐依据保持稳定可审计。
