# 联网搜索非阻塞补充动作要点，并显式标注模型知识回退

状态：已接受（2026-07-22）

TrainPal 在基础方案形成后，针对每个已确认身份的动作独立使用火山方舟 Web Search 补充带可点击引用的动作要点；待确认动作在身份确认前不补充。该过程不阻塞方案展示、编辑或训练，训练中也不再联网；搜索不可用或失败时可以使用模型世界知识生成通用建议。由于模型世界知识无法提供可核验出处，它必须标记为 `model` 并显示为“TrainPal 通用建议”，只有来源视频或保留有效网页引用的内容才能称为“来源化动作要点”。单个动作只能返回 `ready | no_reliable_tip | failed_retryable`，其失败不影响其他动作或基础方案；成功结果保持稳定，重试只针对失败或无可靠要点的动作，不静默重新生成成功内容。这一选择在可追溯性、竞赛开发时间和训练连续性之间取舍，同时避免为首版引入第三方搜索服务与额外凭据。
