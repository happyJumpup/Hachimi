# 内容理解 Provider 明确声明完整、部分或证据不足

状态：已接受（2026-07-22）

内容理解 Provider 的终态覆盖只能是 `complete | partial | insufficient`。`complete` 仅表示检查范围覆盖完整视频，不承诺所有动作判断绝对正确；`partial` 必须列出已覆盖和未覆盖范围，并允许可靠动作继续进入基础方案；`insufficient` 表示没有足够可靠证据形成基础方案，产品提供重试和手工创建动作。静音、没有字幕或 ASR 无结果不能单独构成证据不足，仍必须尝试视觉理解。部署支持的文件大小、视频长度和安全等待上限由技术验证后通过能力配置声明，不写成品牌层的固定承诺。该合同以诚实展示覆盖范围换取广泛接受本地视频输入，而不把“可以上传”误写为“保证准确解析”。
