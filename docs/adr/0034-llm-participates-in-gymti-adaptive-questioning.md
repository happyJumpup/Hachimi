# LLM 参与 GYMTI 自适应选题

状态：已接受（2026-07-23）

> 2026-07-23 取代注记：本文末尾“竞赛生产默认关闭、匿名固定本地降级、依赖评委会话与分析额度”的准入部分已由 [ADR-0044](0044-gymti-uses-ark-doubao-minimal-data-and-independent-concurrency.md) 取代。LLM 仅选合法题目、严格校验和失败时确定性降级等其余决策继续有效。

GYMTI 保留 LLM 对下一道题的参与：它根据当前问卷状态，从版本化题库的合法候选中决定后续探查方向，相同的局部答题状态可以进入不同题目路径；这种不可复现性是产品希望保留的探索感和神秘感，而不是需要消除的技术缺陷。我们接受路径级随机性会增加测试与分析成本，但 LLM 只拥有选题权，不能现场生成或修改题干、选项与计分映射，也不得改写既有回答、突破 5 至 8 题限制、绕过正式结果成立条件或直接保存教练风格；服务端校验其返回的题目 ID，最终计分、结果有效性与风格推荐仍由版本化合同校验。模型超时、调用失败、返回非法题目或当前环境未获模型预算时，由本地版本化规则对规范排序后的合法候选执行确定性降级，问卷不会因失去模型服务而中断；确定性降级不冒充 LLM 的路径差异。模型输入由服务端根据已验证的稳定回答 ID 和共享合同派生，只含版本、稳定 ID、语义标签、计分态势、缺失信号和候选探查目标，不发送展示文案、身体档案、身份信息、训练历史、已确认风格或自由用户画像。竞赛生产环境默认关闭 GYMTI 模型；即使注入密钥，匿名会话也只能使用本地降级，只有显式开启且通过现有评委会话、并发与尝试预算门禁的请求才可以调用模型。
