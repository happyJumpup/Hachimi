# 0013：长视频本地基准中的 Qwen 临时对象自动失效例外

状态：已接受（2026-07-22）

## 背景

ADR-0006 要求分析材料在成功、失败和取消后清理。7/19 分钟路线验证的 Qwen3-VL 原生上传接口会创建 DashScope 临时 OSS 对象；该受控上传链路向调用方提供 48 小时自动失效生命周期，但不提供同一链路可验证的逐对象删除接口。

把这个限制悄悄当成“已删除”会破坏实验的清理门禁；把它扩展到产品媒体又会扩大用户数据边界。因此需要将它限制为一次明确、可审计的本地研究例外。

## 决策

1. 本决策只适用于 Git 忽略目录下、团队已授权的 7/19 分钟长视频本地 A/B 基准；不适用于产品 API、受控来源清单、COS/CDN、用户媒体或未来部署。
2. Qwen 临时 OSS 对象使用提供方声明的 48 小时自动失效策略。运行只记录失效时间、提供方、模型、媒体类别和清理结果；对象键、URL、原始媒体、转录、提示词和响应一律不进入提交内容或脱敏报告。
3. 运行器必须在每次 Qwen 上传后立即将失效时间原子写入 Git 忽略的脱敏 lifecycle journal，并将缺失、过期异常、上传结果不明确、取消或生命周期校验失败记为到期留痕或清理失败；这样的 arm-run 不得成为有效质量或成本结论的一部分。
4. 48 小时后必须在忽略的本地审计材料中确认自动失效已经发生，或明确标记为未验证。未验证的实验不能升级为生产 Provider 决策；在此之前，脱敏报告必须明确写出该升级已被阻止。
5. Seed 联系表使用内嵌图像，不创建 Ark 文件。若后续路线改为创建 Ark 临时文件，仍必须按 ADR-0006 即时删除并验证，不可援引本例外。

## 结果

- 长视频实验不会把“自动失效”伪装成即时删除。
- 原始材料仍不进入仓库、产品数据面或公开部署。
- 生产接入必须在目标服务器重新评估 Provider 删除能力和用户媒体边界，不能直接继承本研究例外。
