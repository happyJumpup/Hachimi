# TrainPal 编排三个领域 Skill

状态：已接受（2026-07-22）

唯一的 TrainPal Agent 通过确定性外层流程编排三个领域 Skill：内容理解完成后必须先由训练编译 Skill 形成可立即使用的基础方案；动作要点补充 Skill 随后按已确认动作非阻塞运行；个性化调整 Skill 只在用户主动选择时运行，并且不等待动作要点完成。待确认动作被确认后只触发该动作的要点补充。三个 Skill 不互相调用，也不进入无限规划、反思或工具调用循环；语义判断留在各 Skill 内。它们共用只包含 `task_id`、任务类型、合同与 Skill 版本、输入版本和输入指纹的任务信封，各自保留独立载荷，不接收原始媒体、不写草稿、不读取训练状态机。内容理解 Provider、联网搜索与 Schema 校验是工具或适配边界，确定性训练引擎仍是代码而非 Skill，从而让三个领域能力可迁移到其他内容理解 Provider，而不制造万能 Agent 上下文或不可预测的运行链路。
