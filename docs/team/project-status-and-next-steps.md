# 本地视频训练原型：项目状态与下一步

> 更新于 2026-07-23。竞赛 Web MVP 是已完成的工程基线；五分钟后端与两个前端任务正在独立工作树收口，只有跨分支集成、真实 CloudBase Canary 和回滚通过后才能宣称竞赛版完成。

## 1. 当前方向

产品从“团队受控视频证明闭环”进入“用户导入自己有权使用的本地视频”验证：

`本地视频导入 → 显式完整分析 → 来源时间线与覆盖反馈 → 可编辑方案 → 训练与复练`

- 本地视频是主入口，受控视频是快速体验与能力不可用时的兜底。
- 原视频保存在当前设备浏览器；服务端只接收单次分析的临时副本并在终态清理。
- 页面切换、刷新和 SSE 短暂断线不取消分析；用户返回后凭 `run_id` 恢复真实状态。
- 过程展示真实已处理时长与暂时候选数。可靠部分结果保留覆盖缺口和逐段重试，不能冒充完整分析或无动作。
- Agent 保留来源证据与不确定标记，循环内容按真实顺序展开为扁平动作安排，不把内部教学／跟练判断暴露为公共字段。

## 2. 已有基线与今晚原型边界

竞赛基线已经具备受控视频整段分析、跨视频草稿、可恢复训练、记录、卡路里约值、Pet 五态、海报与单实例部署合同。它继续作为受控快速体验和回归基线，但旧的“受控来源唯一入口”“离页即取消”“60 秒是产品上限”已由 ADR-0013 取代。

下一轮原型冻结了以下最小纵切片：

- Dexie 保存本地视频 Blob 与稳定 `local:<UUID>`，方案和训练引用同一来源；媒体丢失时支持重新选择并校验。
- `GET /api/v1/capabilities` 公开当前上传开关、分析秒数上限和字节上限。
- `POST /api/v1/analysis-runs/local` 以 multipart 创建完整分析或绝对区间重试，沿用现有运行查询、SSE 与取消接口。
- `AnalysisRunView` 提供来源时长、已处理时长、暂时候选数、`complete | partial | insufficient` 覆盖状态和覆盖缺口；公开候选不再包含 `segment_role`，用户通过确认、编辑或删除校正结果。
- Web 在离页／刷新后恢复同一运行，中间结果只读；覆盖缺口逐项重传本机 Blob，按绝对时间合并可靠结果。

当前竞赛后端已把能力合同和分块实现收敛为完整源文件不超过 5 分钟：一次 ASR、60 秒视觉块、10 秒重叠、单块 20 秒和整次 180 秒。它已通过本地 API／类型门槛，但目标 CloudBase 的真实五分钟、三并发、临时材料清理与回滚尚未通过，因此不能把“已实现”写成“已上线”。

## 3. 技术路线 benchmark 结论

native audio/video benchmark 任务仍在独立工作树验证。任何尚未提交且未通过证据、结构、清理和无虚构参数硬门槛的结果都不能接入比赛版；当前没有可以据此宣布的 Seed／Qwen 质量冠军。

因此当前结论是：

- benchmark 证据可用于排除不满足门禁的组合和指导后续测试，但不能当作生产 Provider 选型结论；
- 下一轮原型保持现有生产 Provider，不因为单次 spike 改路由；
- 当前 Provider 分块基线保持为生产候选；只有目标部署验收通过后才启用 300 秒公开能力；
- 后续若切换 Provider，需引用复核后的 benchmark 证据并新增技术路线 ADR，不能只改环境变量后对外宣称升级。

## 4. 尚未完成的验收

以下项目通过前，状态只能表述为“原型迭代中”：

1. 等待两个前端任务提交，合并 API、Web 与本组文档分支，重新生成并核对 OpenAPI／前端类型，确认 wire contract 无漂移。
2. 验证本地 Blob 导入、刷新恢复、重新选择、清除数据与 v2→v3 无损迁移。
3. 验证页面切换、刷新、SSE 断线、显式取消、换源和迟到事件的不同生命周期。
4. 构造部分覆盖结果，确认可靠候选可使用、每个缺口可单独重试，成功与失败合并都不丢失已有结果。
5. 验证完整、部分、空、系统失败、容量繁忙、上传关闭、超限和媒体丢失的文案与操作相互区分。
6. 对服务端上传副本、音频、帧、转录和 Provider 材料执行所有终态清理审计；确认日志与构建不含文件名、媒体、密钥或 Provider 正文。
7. 构建并审计签名 FFmpeg 镜像，完成 CloudBase 版本 A、版本 B、真实短视频、外部裁剪五分钟样本、三并发／第四路 429 和 B→A→B 回滚。

## 5. 暂缓项

- GymBTI 计算细节：等待独立方案，不改变当前卡路里合同。
- 正式产品名：继续暂缓；哈肌咪是 Agent／Pet 名称，不自动成为产品品牌。
- Pet 新能力：保持既有五态、可隐藏和非阻塞边界，不新增对话、示范或训练控制。
- 10 分钟生产能力、Provider 切换、账号与跨设备媒体同步、云端视频库、任意 URL 或平台登录态导入。
