# 竞赛 Web MVP 产品规格

> 历史竞赛基线：下一轮原型的入口、分析生命周期和真实能力边界以 [本地视频训练原型规格](local-video-training-prototype.md) 与 [ADR-0013](../adr/0013-local-video-import-and-recoverable-analysis.md) 为准。本文件继续记录已完成的受控视频竞赛闭环。

Status: frozen for implementation

Issue: #3

Primary viewport: 390×844

Audience: 评委、现场访客、开发与验收人员

## 1. 目标

在竞赛现场提供一条可由真实用户独立完成、可在公网访问的训练闭环：

1. 从团队配置的来源视频中寻找训练动作；
2. 明确点击后对整段受控视频触发真实动作分析，校正并选择动作候选；
3. 把来自不同视频或没有参考视频的动作编排为方案；
4. 另存为可复用方案并开始训练；
5. 完成次数型或时长型动作、休息、中断恢复和结束训练；
6. 查看约消耗卡路里、训练记录，并为完整训练生成分享海报。

产品仍是轻量训练体验，不扩展为完整健身 App。动作分析 Agent 只提出动作候选，用户决定动作、参数、顺序和是否开始训练。

## 2. 两类体验路径

### 2.1 评委主路径：真实 AI 闭环

评委输入现场提供的体验码后获得预留分析容量。标准演示路径为：

`来源视频 → 点击分析视频动作 → 整段真实分析 → 校正并多选候选 → 方案草稿 → 另存为或直接训练 → 完成训练 → 海报分享`

- 页面必须明确显示真实分析阶段，不显示伪造百分比。
- 分析成功、无动作证据、系统失败和容量繁忙必须是不同结果。
- 真实分析失败时可以重试、换视频或创建自建动作；不得回填预置候选冒充分析结果。
- 评委可以继续切换视频，使同一方案包含多个来源视频。

### 2.2 访客路径：快速体验训练

访客无需等待分析即可选择“快速体验方案”，直接进入方案预览或训练。该方案是团队预先配置的演示内容，必须标注“快速体验方案”，并与真实 AI 入口视觉分离。

- 快速体验方案不得出现在分析候选面板中，也不得使用“AI 已识别”等文案。
- 访客仍可使用公共实时分析名额；容量不足时显示繁忙状态，不影响快速体验方案。
- 快速体验路径覆盖训练、休息、Pet、卡路里、记录和完整训练海报，因此即使现场云服务拥堵，访客仍能体验产品价值。

## 3. 核心界面

六个核心界面由五条路由承载；“休息／暂停”是训练路由中的独立界面状态，不新增路由。

| 核心界面 | 路由 | 主要任务 | 主操作 |
| --- | --- | --- | --- |
| 视频与动作分析 | `/` | 选择来源视频、触发整段分析、校正并加入动作 | 分析视频动作 |
| 方案编辑 | `/plan` | 跨视频编排、手工新增、编辑参数、另存为 | 开始训练 |
| 我的训练 | `/mine` | 找回草稿、未完成训练、方案和记录 | 继续训练／打开方案 |
| 训练中 | `/training` | 观看演示片段并完成当前组 | 完成本组／开始计时 |
| 休息／暂停 | `/training` | 等待休息结束或由用户决定继续 | 准备继续／继续训练 |
| 完成结果与海报 | `/result/:recordId` | 查看结果并分享完整训练 | 分享／下载海报 |

存在未完成训练时，除训练页以外的产品页面都显示“继续训练”入口。它只召回当前训练场次，不在后台继续动作训练。

## 4. 页面行为合同

### 4.1 视频与动作分析

- 只展示后端配置且不超过 60 秒的受控视频源；用户不能提交任意路径或 URL。
- 用户选择来源后点击“分析视频动作”，视频暂停并进入整段分析；当前播放时间不改变范围。
- 页面加载、播放、暂停、拖动进度条和切换来源都不会自动创建分析请求。
- 分析中展示真实阶段名称和“取消”；取消、切换视频或离开页面都会使本次结果失效。
- 候选支持预览片段、修改名称和时间范围、多选，并按列表顺序加入草稿。
- 空结果提示“这段视频里没有找到明确动作”，并提供“重试”和“创建动作”。
- 系统失败提示“这次没有分析成功”，并提供“重试”；不得伪装成没有动作证据。
- 容量繁忙提示“现在体验的人较多，请稍后再试”，同时保留“使用快速体验方案”。

### 4.2 方案编辑

- 一份自动保存的当前草稿可以组合多个视频动作和自建动作。
- 用户可以上移、下移、复制、删除动作，编辑名称、动作模式、组数、次数或时长、休息时间和重量。
- 自建动作不显示原视频、演示片段或自动匹配的替代视频。
- “另存为”要求输入方案名称，并在方案库创建独立副本；开始训练不会自动保存为方案。
- 空草稿提供“继续找动作”“创建动作”和“使用快速体验方案”。
- 开始训练前只做可执行字段校验和非阻塞安全提示，不评价训练效果或伤病风险。

### 4.3 我的训练

- 依次呈现未完成训练、当前草稿、已存方案和训练记录；没有内容的分区不占据首屏主位置。
- 同一设备最多一场未完成训练。存在未完成训练时，“继续训练”是首要操作，同时允许用户明确结束。
- 训练记录区分“已完成”和“提前结束”，并保存当次方案快照和实际完成量。
- 提供“清除本机训练数据”，二次确认后清除档案、偏好、草稿、方案、未完成训练和记录。

### 4.4 训练中

- 顶部展示动作序号和总数，中部展示视频动作的演示片段或自建动作的无视频状态，底部展示本组目标和唯一主操作。
- 次数型动作由用户点击“完成本组”；时长型动作由用户点击“开始计时”，前台倒计时结束后完成本组。
- 离开页面或页面不可见时，动作训练暂停且不累计活动时间。
- 用户可以暂停、恢复、隐藏或显示哈肌咪、跳过当前动作剩余组、提前结束整场训练。
- 跳过只保留实际完成量；提前结束需要确认，并生成“提前结束”记录。

### 4.5 休息与暂停

- 完成本组后按动作安排进入休息；休息采用绝对截止时间，即使离开训练页也继续流逝。
- 倒计时归零后进入“准备继续”，不自动开始下一组。
- 主动暂停、页面恢复和休息结束均由用户点击“继续训练”或“准备继续”返回训练。
- Pet 在休息时使用“休息”状态，在主动暂停和“准备继续”时使用“暂停”状态。

### 4.6 完成结果与海报

- 完整训练显示方案名称、训练时长、约消耗卡路里、完成动作数和完成态哈肌咪。
- 海报固定为 1080×1920 PNG，只包含上述字段，不包含动作组数明细、训练档案或来源视频。
- 优先调用 Web Share API；不支持或分享失败时提供“下载海报”。
- 提前结束显示实际完成摘要并写入记录，但不生成“完成海报”。
- 用户可选择“再练一次”“查看记录”或“继续找动作”，不使用“返回信息流”。

## 5. 全局结果状态与文案

| 状态 | 用户可见结果 | 后续操作 |
| --- | --- | --- |
| 成功 | 直接展示候选、保存结果或完成结果 | 执行当前主任务 |
| 空结果 | 说明整段视频没有明确动作证据，不归因于用户 | 重试、创建动作、继续找动作 |
| 可恢复错误 | 简短说明未成功，不显示模型、请求 ID 或技术日志 | 重试、返回视频、使用快速体验方案 |
| 容量繁忙 | 明确是当前体验人数较多，不进入无期限队列 | 稍后重试、使用快速体验方案 |
| 未完成训练 | 说明上次进度已保存在本机 | 继续训练、结束训练 |
| 提前结束 | 展示实际完成量并标注“提前结束” | 查看记录、再练一次 |

加载过程使用真实动作名称，例如“正在读取视频”“正在理解语音”“正在定位动作”“正在整理候选”。界面不显示模型思维过程、置信度、虚假进度或内部供应商名称。

## 6. 冻结范围

### 本次必须完成

- 2–3 条团队授权受控视频和跨视频动作编排；
- 真实 ASR、视觉理解与候选融合；
- 自建无视频动作、草稿自动保存和方案另存为；
- 次数型／时长型训练、休息、暂停、恢复、跳过和提前结束；
- 性别、年龄、身高、体重训练档案和单一卡路里约值；
- 固定哈肌咪 Pet 的五种状态与长期隐藏偏好；
- 我的训练、训练记录、完整训练海报和分享／下载；
- 公网 HTTPS 部署、评委预留容量和访客快速体验方案。

### 本次明确暂缓

- 抖音小程序、信息流触发和待练清单入口；
- 用户上传视频、任意 URL 或来源抓取；
- Pet 选择、自定义形象、动作示范或 AI 教练能力；
- 账号登录、服务端训练数据库和跨设备同步；
- 一键生成训练方案、健康诊断、伤病适配、动作质量评分；
- 周目标、提醒、社交社区、排行榜和长期训练周期。

## 7. E2E 验收

竞赛 Web MVP 只有在以下场景全部通过后才算完成：

1. **评委真实 AI**：输入体验码，选择视频 A，点击整段真实分析，校正并加入候选；切换视频 B 再加入动作，草稿保留两个来源。
2. **空、错、繁忙分离**：测试 Provider 分别返回无动作证据、系统失败和容量不足，界面出现三套不同文案与操作，且没有预置候选回填。
3. **方案可执行**：加入自建动作，修改模式与参数、排序、复制、删除、另存为；刷新后草稿和方案均恢复。
4. **完整训练**：完成至少一个次数型和一个时长型动作；休息时离开训练页，倒计时继续；返回后必须点击“准备继续”。
5. **中断恢复**：动作进行中隐藏页面或刷新，活动时间停止；再次进入时从已保存进度恢复为暂停状态。
6. **实际完成量**：跳过剩余组与提前结束均不把未完成组计入结果；提前结束写入记录但不生成完成海报。
7. **Pet 非阻塞**：五种状态与训练状态匹配；隐藏偏好跨刷新保留；资源加载失败时训练仍可完成。
8. **结果分享**：完整训练生成字段正确的 1080×1920 PNG；Web Share 可用时分享，不可用时下载。
9. **访客快速体验**：无体验码用户可以从明确标注的快速体验方案进入训练，并能识别它不是 AI 分析结果。
10. **视口与输入**：390×844、Android Chrome、iOS Safari 和桌面竖屏舞台下，主操作可见、触控区域有效且无横向滚动。
