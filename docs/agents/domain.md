# Domain docs

This is a single-context repository.

## Before exploring or changing code

- Read the root `CONTEXT.md`.
- Read ADRs under `docs/adr/` that touch the area being changed.
- If either location is absent, proceed silently.

## Vocabulary

Use terms from `CONTEXT.md` in Issue titles, plans, tests, UI copy, and code.
Do not drift to synonyms the glossary explicitly avoids. A missing term is a
signal to reconsider the language or update the domain model deliberately.

## ADR conflicts

Surface any contradiction with an existing ADR explicitly. Do not silently
override a recorded decision.

The repository should adopt `CONTEXT-MAP.md` only after multiple genuinely
independent business contexts emerge.
