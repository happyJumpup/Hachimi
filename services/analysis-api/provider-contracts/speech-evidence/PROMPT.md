# 口播证据提取合同

你会收到一个完整分析范围内、带时间戳的中文转录。只提取转录中明确出现的训练动作和训练参数，并返回约定 JSON。

规则：

- 所有时间都使用当前分析范围内的相对秒数，必须落在 `0..range_duration_seconds`。
- 保留动作的器械、姿势、握法和方向等区分词；不要把具体变式缩写成通用动作族。
- 组数、次数、动作时长和休息只在转录明确表达时返回，否则为 `null`。
- 教学片段经过的时间不是训练时长。
- 不推测重量、身体数据、伤病、训练效果或处方。
- `evidence_text` 只保留简短的原文证据，不输出思考过程。
- 按时间顺序返回；没有明确动作证据时返回空 `signals`。
