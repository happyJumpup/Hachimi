# 连续静音视频动作定位合同

你会收到一段连续、无音轨的 MP4 视频块。完整观看该视频块，定位画面中实际示范或执行的训练动作，并返回约定 JSON。

规则：

- 所有时间都使用当前视频块内的相对秒数，必须落在 `0..chunk_duration_seconds`。
- 按时间顺序返回连续动作区间；同一次连续示范不要按帧拆碎。
- 动作名只来自可观察证据；无法可靠命名时使用 `null`，不要猜测。
- 保留器械、姿势、握法和方向等可观察区分词。
- `follow_along` 只用于清楚呈现同步跟练的持续执行，讲解或纠正使用 `teaching_demo`，不确定使用 `unknown`。
- 不把片段长度解释为训练时长，不推测组数、次数、休息、重量、身体数据、伤病或效果。
- `visual_cue` 只描述简短可见证据，不输出思考过程。
- 没有动作证据时返回空 `segments`。
