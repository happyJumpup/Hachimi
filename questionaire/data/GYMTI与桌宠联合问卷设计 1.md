# GYMTI 与猫咪桌宠联合问卷设计

这套问卷的目标不是做两份测试，而是让用户一次答完，同时得到两个结果：

1. **GYMTI / PYTI 健身人格**：用户为什么练、怎么练、卡在哪里、适合什么训练产品。
2. **猫咪桌宠风格**：用户最适合被哪种语气陪伴、提醒、督促、安慰或挑战。

两套结果不要一一绑定。比如 IMNB 肌肉人可能适合“专业数据型”猫，也可能适合“毒舌督促型”猫；HIDE 新手潜行者可能适合“温柔陪伴型”，也可能适合“幽默话痨型”。GYMTI 看的是训练行为，桌宠看的是互动偏好。

## 计分方法

每题单选。每个选项同时给 GYMTI 和桌宠风格加分，也可以对明显不适配的类型扣分。

建议实现方式：

- GYMTI 主结果：统计 `G:` 后的分数，最高者为主结果。支持 `+1/+2/+3` 和 `-1/-2`。
- 桌宠主结果：统计 `P:` 后的分数，最高者为主桌宠。支持 `+1/+2/+3` 和 `-1/-2/-3/-5`。
- 如果 GYMTI 前两名只差 1 分，输出“主人格 + 副人格”，例如 `KCAL 主 / CURV 副`。
- 如果桌宠前两名只差 1 分，允许输出“主桌宠 + 辅助语气”，例如 `温柔陪伴型，偶尔幽默话痨`。
- 第 16-18 题更偏桌宠语气，可以给桌宠较高权重。
- 罚分建议：
  - `-1`：轻微不适配，只用于拉开同分，例如怕无聊的人不太适合过度安静的陪练。
  - `-2`：明确抗拒，例如“太凶会静音”要扣毒舌/挑战，“太累会逃走”要扣热血/挑战。
  - `-3`：强烈反向偏好，例如明确害怕某种桌宠人格，但还没有到完全不能接受。
  - `-5` 或 `定为不可能`：安全阈值。用户明确说会被伤害、会静音、会自我攻击时，该桌宠风格不应成为主结果。
  - GYMTI 扣分要保守，主要用于排除强冲突倾向；桌宠扣分可以更重，因为语气不适配会直接导致用户关闭提醒。

一句话解释：

## 产品实现建议

1. 问卷前半段更偏 GYMTI，后半段更偏桌宠，但所有题都双计分。
2. 桌宠不要根据 GYMTI 自动决定，必须尊重第 16-18 题的语气偏好。
3. 结果页先展示 GYMTI，再展示桌宠，因为用户最想先知道“我是哪种人”。
4. 桌宠结果可以直接影响后续通知文案、训练中提示、休息日提醒、失败召回。
5. 如果用户选项高度分散，可以输出“混合型”描述，但内部仍保留最高分用于推荐。

## 示例组合

- `IMNB + 专业数据型`：肌肉人配专业数据猫。文案可以更硬核：容量、重量、恢复、PR。
- `IMNB + 毒舌督促型`：肌肉人配毒舌猫。适合轻微嘴臭式督促。
- `HIDE + 温柔陪伴型`：新手潜行者配温柔猫。重点是降低羞耻和启动成本。
- `KCAL + 专业数据型`：卡路里收纳师配数据猫。重点是趋势线，避免单日数字审判。
- `LIFE + 佛系陪练型`：续命打工人配佛系猫。重点是小剂量、长期、无压力。
- `BOOM + 热血鼓励型`：老暴汗家配热血猫。重点是点燃情绪和课程氛围。
- `CURV + 幽默话痨型`：线条精修师配幽默猫。重点是审美反馈、轻松陪伴和打卡表达。
- `WINN + 专业数据型`：赢麻者配专业数据猫。重点是周期、负荷、恢复和赛事目标。
