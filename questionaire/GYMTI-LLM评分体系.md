# GYMTI 与猫咪桌宠 LLM 评分体系

## 目标

用 5-8 道题同时判断两件事：

- GYMTI：用户的健身倾向、阻力来源和产品需求。
- 猫咪桌宠：用户愿意长期保留的陪练语气。

两条结果独立计分，不做一一绑定。LLM 负责选题和解释，本地分数规则负责最终类型。

## 双轨计分

每个选项同时写入两组分数：

```text
G: WINN +1, IMNB +1 / P: 挑战突破型 +1
```

分值建议：

- `+1`：弱信号或辅助风味。
- `+2`：强信号。
- `+3`：明确偏好，常用于桌宠语气题。
- `-1`：轻微不适配，主要用于拉开同分。
- `-2`：明确抗拒。
- `-3`：强烈反向偏好。
- `-5` 或 `定为不可能`：安全阈值，该桌宠风格不能作为主结果。

GYMTI 扣分要保守；桌宠扣分可以更重，因为语气不适配会直接导致用户静音或关闭软件。

## 可跳过的个人信息

在正式 GYMTI 问题完成后、人格/宠物测评结果展示前，插入一个可跳过的信息收集步骤：

- 您的身高，单位 cm。
- 您的体重，单位 kg。
- 您的性别，可选择女、男、其他、暂不说明。

提示语必须明确说明：

```text
以下信息可以跳过。填写后仅用于个性化健身负荷生成和训练建议，不参与 GYMTI 人格和猫咪桌宠语气计分。
```

处理规则：

- 用户点击跳过时，不降低问卷置信度，也不补问。
- 身高、体重、性别不进入 `G:` 或 `P:` 分数。
- 如果身高体重都填写，可计算 BMI，并用于后续起始负荷、动作难度和恢复建议的辅助参考。
- 如果信息缺失，训练负荷生成应从保守默认值开始，再用训练反馈逐步校准。

## 自适应抽题

推荐题量：最少 5，最多 8。

抽题顺序：

1. 前 1-2 题优先问广谱行为题，用来铺开 GYMTI。
2. 第 3 题后观察当前前两名，优先问能区分接近类型的问题。
3. 后半段优先补桌宠语气题，尤其是提醒、纠错、漏练召回、害怕哪种猫。
4. 若用户多次选择“没有符合我的描述”，延长到最多题数并降低置信度。

停止条件：

```text
top_gymti_score >= 4
top_pet_score >= 4
gymti_gap >= 3
pet_gap >= 3
answered_count >= 5
```

若任一条件不满足，继续追问，直到 8 题或题库用完。

## LLM 使用边界

LLM 可以做：

- 从候选题里选下一题。
- 解释为什么这些回答导向当前结果。
- 生成猫咪台词、产品建议和结果页文案。

LLM 不可以做：

- 绕过本地分数改最终类型。
- 忽略 `定为不可能`。
- 发明题目替代候选题，除非任务是设计新题库。
- 用羞辱身体、体重、能力、懒惰或心理状态的方式制造趣味。

## 推荐输出

输出结构：

```json
{
  "gymti": "IMNB",
  "gymtiSecondary": "WINN",
  "pet": "专业数据型",
  "petSecondary": "挑战突破型",
  "confidence": "high",
  "summary": "一句有趣但不羞辱的解释",
  "nextActions": ["训练容量统计", "PR 记录", "恢复提醒"],
  "petLines": ["本组完成度不错，下一组把动作质量也算进胜利。"]
}
```

已沉淀为 Codex skill：

```text
gymti-pet-matcher
```
